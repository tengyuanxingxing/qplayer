安卓手机请下载 **QPlayer-1.9.10-custom-debug.apk**。QQ、网易云、汽水插件可以从本页附件分别下载；也可以下载“安装包与音源插件.zip”一次获取全部文件。

这是基于 [TIMER-err/qplayer](https://github.com/TIMER-err/qplayer) 的个人定制测试版，并非原作者官方发布。本次提供 Android 8.0+、arm64-v8a 安装包。

### 新功能
- 播放页增加“歌曲信息与推荐 / 封面 / 歌词”三页：封面页手指左向右划打开信息，右向左划打开歌词。
- 放大播放、暂停、切歌、循环和收藏按钮；提供小、中、大三档播放页字号。
- QQ 与网易云统一“我喜欢”，刷新同步；同一录音去重后只选一个播放源，可设置优先平台。
- 应用内评论列表，支持热评、最新、分页与重试，需要同页配套 QQ / 网易云插件。
- 歌曲搜索增加歌手入口；歌手页提供歌曲与专辑，以及全部 / 专辑 / 现场专辑 / EP / 单曲筛选和分页。
- 底栏改为“首页 / 我的”，启动默认进入“我的”；首页提供推荐卡片、三首一组歌曲推荐及红心探索。

### 优化
- 搜索列表复用固定数量的歌曲行，跨过一行只更新一个进入视口的行，减少封面与文字重复刷新。
- 一万首歌曲的行复用、快速定位与回滑后的点击索引已通过回归检查。
- 封面取色背景、大圆角封面与歌词排版参考用户提供的界面。
- 推荐使用来源实际返回的数据，红心探索以收藏中的歌手补充，不保证与 QQ 官方推荐结果相同。

### 修复
- 仅点击歌词文字实际区域才跳转进度；滑动、空白与取消触摸不触发跳转。
- 歌曲行滑动、长按、锁屏失焦取消触摸，避免松手或恢复后误切歌。
- 汽水二维码和轮询使用一致设备标识，处理数字扫码状态、授权跳转和 Cookie 合并；真实账号验证通过才显示登录成功。
- 修复 QQ 歌手搜索旧接口空结果，增加候选歌手接口回退。
- 修复信息页文字对比度、单歌手入口被播放层遮挡与专辑筛选面板被底部控件遮挡。

### 安装与保留登录
1. 点击本页 APK 下载到手机，打开文件并按系统提示允许安装。
2. 如果已安装 **1.9.9-custom-debug**，直接覆盖更新，**不要先卸载或清除数据**。本版 versionCode 为 109，应用 ID 仍为 `dev.t1m3.qplayer.debug`，签名与上版一致，可保留登录凭据、缓存和设置。平台凭据本身过期时仍需重新登录。
3. 在音源管理中直接导入本页三个 `.qplug` 并启用；它们是本地修改的未签名包，按应用提示确认。相同插件 ID 更新保留凭据。
4. 上游正式版使用不同签名，本测试版会与其并存，无法继承正式版私有登录数据。
5. “我的”顶部打开“我喜欢 · 全部平台”，可刷新同步与选择优先播放源。专辑筛选作用于已加载数据，可继续加载更多；未知分类保留在“全部”。
