### 手机上怎么更新
1. 下载本页 APK，覆盖安装此前的定制版，打开新版 **QPlayer（debug）**。
2. 进入“我的 → 设置 → 插件”，下滑至页面底部，点击“刷新列表”。
3. 已安装插件：点击网易云 / QQ / 汽水右侧的“设置”，在更新卡片中点击“更新”，再确认安装权限。
4. 未安装插件：在“可安装”中点击定制版的“查看”，进入后点击“安装”，再确认权限。
5. 更新后版本应为 **网易云 0.5.8.3、QQ 0.7.3.3、汽水 0.1.2**。

原作者正式版是不同应用 ID / 签名，不会因更新本测试版自动读取正式版私有登录数据；请确认打开了新版应用。平台凭据自身过期时仍需重新登录。
