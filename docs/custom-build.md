# 播放页与统一收藏改版

- 手机竖屏有“信息与推荐 / 封面 / 歌词”三页。从封面用手指由左向右划是信息页，由右向左划是歌词页；纵向滚动与横向翻页锁定方向。
- 封面采用大圆角方图，暂停时保持尺寸；背景按封面主色生成安静的深色渐变。
- 放大播放、切歌、循环及收藏按钮，保留小屏自适应。
- 小／中／大字号分别使用 16／20／24 的歌词字号，歌名与歌手同步调整，设置持久保存。
- 点击歌词时检查按下与抬起是否命中同一句的真实绘制边界，滑动及空白区域不跳进度。
- 新增全部平台“我喜欢”，进入或刷新时拉取各已登录来源的收藏；歌曲详情每批 100 首。
- 使用录音标识、歌名、歌手、版本与时长去重；不确定的版本保留。
- 重复录音只保留一个播放队列条目，可选 QQ／网易云优先，已知受限或试听来源降低优先级。
- 收藏与取消收藏写回当前歌曲所属平台；平台筛选可以查看与操作各自的收藏。
- 每个账户单独保存收藏快照；失败时保留已获取的内容，确认的取消收藏仍移除。
- 新增应用内只读评论面板（最新、热评、分页、重试），需配套评论插件。
- 歌曲行仅接受短按；滑动离开再返回、长时间按住、取消的触摸均不激活播放。
- 安卓锁屏、失焦或暂停时取消触摸流，并丢弃旧触摸事件，防止恢复后补发切歌。
- 底栏仅保留“首页 / 我的”，默认进入“我的”，搜索从首页顶部进入。
- 首页增加横向推荐卡、三首一组的歌曲推荐与红心探索；使用音源实际推荐，并用收藏歌手的歌曲补充探索。布局参考提供的截图，推荐结果由音源和个人收藏决定，不承诺与 QQ 官方算法一致。
- 搜索歌曲时提供歌手入口；歌手页提供歌曲、专辑分页，以及全部 / 专辑 / 现场专辑 / EP / 单曲筛选。筛选按来源提供的类型作用于已加载专辑，可以继续加载更多；未知类型保留在“全部”。
- 搜索列表改用固定槽位复用：跨过一行只更新进入视口的一个歌曲行，保留重叠行的封面与文字缓存；移除重复的加载更多检查。
- 汽水登录插件保持二维码和轮询设备标识一致，识别数字状态，逐跳合并授权 Cookie，并在真实账号验证通过后才报告成功；设备标识和凭据一同持久保存。

## 1.9.12 的本轮修复

- 横向翻页直接跟随手指，封面、双页标题、信息与宿主歌词使用同一连续页位置；松手后对齐目标页，短距离拖动可取消返回。滑动时暂停封面阴影和歌词的额外模糊绘制。
- 顶栏取消封面／歌词切换按钮；封面页在原位置显示唯一评论按钮。封面歌手下方显示随音频时钟更新的当前歌词。
- 多歌手选择面板直接在播放页绘制；保留播放器背景和返回路径，不先跳回歌单。评论面板的行高与纵向位置显式计算，支持实际点击进入。
- 字号变化先完成上一帧 GPU 工作，再清除旧画面缓存并重新布局；保留正常播放时的缓存复用。
- “我的”歌单网格与列表改用固定槽位复用；歌词手动滚动时暂停额外模糊、阴影与发光开销。安卓为支持的同分辨率屏幕提交高刷新率提示，并关闭分发包的调试模式，保留旧定制版的包名和签名；实际帧率仍取决于设备和绘制时间。
- 首页无歌曲时收起空推荐大卡片和多余高度；歌手头像区与歌曲／专辑共用滚动容器；专辑按已加载数据的发行日期从新到旧排序，未知日期在最后。
- 汽水插件 0.1.3 使用 HTTP 确认模式，保留服务端原始二维码 URL，增加轮询间隔、限流退避和状态提示。匿名真实接口已成功出码并返回等待扫码状态；未将它当作本人扫码成功证明。
- 定制版“检查更新”读取本仓库的 Release 列表，包含预发布；按版本选择已上传完整定制 APK 的版本，跳过草稿、无 APK 与其他安装变体。1.9.11 及更早版本的已安装程序仍带旧更新地址，必须先手动覆盖安装一次 1.9.12。

## 1.9.13 修复

- 账户页的 QQ、网易云、汽水行使用独立坐标和点击区域；切换音源时立即清空旧的登录方式、二维码和轮询。异步返回结果必须匹配来源及本次登录，避免汽水表单套用 QQ 的 App 登录模式。
- QQ 插件 0.7.3.4 使用 `music.radioProxy.MbTrackRadioSvr/get_radio_track` 获取猜你喜欢歌曲，保留登录 Cookie、authst、续期链路。歌曲与歌单独立加载；首页猜你喜欢独立使用 QQ，即使主音源设为网易云也不改变来源。上游拒绝或未返回时明确提示，不虚构推荐。
- 底部播放条整体拦截触摸，空白和进度条打开播放器，播放等独立按钮保留操作；全屏播放器打开时底部条停用。
- 播放器顶部和封面页支持向下滑动收起；信息列表和歌词区的上下滚动继续各自处理，横向翻页与纵向操作保持方向锁定。
- 系统 MediaSession 增加当前歌曲的带时间轴歌词，采用公开 `lyricInfo` 元数据约定；异步歌词到达和偏移调整会刷新，切歌清除旧内容。歌词只在内容变化时序列化并限制大小，不按播放帧反复发送。
- 锁屏元数据约定参考：[LyricInfo 公开序列化格式](https://github.com/limczhh/LyricInfo/blob/main/app/src/main/java/com/lidesheng/lyricinfo/core/LyricInfoSerializer.kt)。未引入 Hook 或要求 root。系统是否展示仍依赖手机厂商、系统版本及音乐卡片设置，当前没有连接手机验证。

## 1.9.14 收藏与交互修复

- 统一收藏的来源筛选、刷新、同步详情与重复歌曲来源偏好收进右上角菜单；封面跟随当前列表第一首歌。
- QQ 插件 0.7.3.5 按实际页长续取，收藏列表已经返回的完整详情会复用；其他歌曲详情拆成最多十个模块。宿主对大批详情的空或残缺结果再分小批补取，完整测试覆盖 1018 首；各平台已解析 / 喜欢 ID 数在同步详情内展示，失败仍保留同账号快照。
- 合并去重保持首次出现的位置，修复同名不同版本被分组后挤到前面的问题。默认以主序来源的原顺序为骨架。
- 通用“分组穿插”可选择主序来源、参与来源、双方区段及每轮首数（1–10），也可分段接续。主序区段以外的歌曲保持先后顺序；跨平台重复录音即使选了另一播放源也保留主序位置，不挪动尾部。配置按两边账号组合隔离，不改平台原歌单；分界被删除时回退原序，等待重设。
- 使用方法：在统一收藏菜单选择来源，再按平台查看；长按歌曲设置区段起点、终点。只设置主序终点时从第一首开始；参与来源默认全部。设置完整后默认 1∶1 穿插，可在菜单改变比例或关闭。
- 播放器下滑采用跟手卡片，拖动时位置直接对应手指，松开根据距离与速度收起或回弹；动画按时间计算，支持上拉反悔和系统触摸取消。原歌词与信息区纵向滚动保留。
- 静态背景预绘制小图缓存，横向翻页时跳过整列透明遮罩，停稳后恢复边缘渐隐；长标题翻页时暂用省略显示，信息页只创建视口附近歌曲，同曲信息避免反复清空重载。
- 同一电脑的 390×844 生产编译场景 CPU 光栅基准，封面→信息中位耗时约 52.5ms → 4.4ms，封面→歌词约 82.0ms → 6.8ms。测试图像与歌曲是明确标注的虚构样本；这不是手机 GPU 帧率或 QQ 音乐等效流畅度的证明。跟手位置、回弹、收起另有实际场景断言及预览。

## 验证

项目要求 JDK 21、Maven，安卓还需要 SDK 34 与 Gradle 8.7。
修改核心后先 `mvn -pl player-core install`；安卓构建：
`cd android-shell` 后运行 `gradlew assembleDebug testDebugUnitTest -Dorg.gradle.jvmargs=-Xmx768m --no-daemon`。

新增测试覆盖 1016 首分批同步、失败缓存、账户隔离、来源选择、版本去重、字号保存、
滑动方向锁定、实际歌词命中区域、歌曲行取消／拖动／长按、10000 首列表行复用和回滑后的点击索引。
还覆盖歌手搜索降级、专辑分类筛选、双入口导航和汽水登录的跳转 / 失败 / 过期 / 重启后设备标识场景。
界面截图来自生产 QML 编译产物与共享歌词绘制层，预览音乐和评论使用标明的测试数据。

Windows 基线测试 `ArtworkResolverTest` 有两项路径分隔符差异，与本次修改无关。
本机未连接安卓设备；手机实际帧率、锁屏动作、个人账号的收藏同步和汽水扫码仍需在手机上验证。汽水修复通过模拟接口流程测试，未声称用个人账号登录成功。

## 安装

新版为 `1.9.14-custom`（versionCode 113），debug 应用 ID 仍为 `dev.t1m3.qplayer.debug`。
已安装此前提供的定制测试版（包括 `1.9.11-custom-debug`）时直接覆盖安装，使用相同本机签名，保留应用数据与登录凭据；不要先卸载。平台凭据本身过期时仍需重新登录。
如果手机装的是上游正式版，本机没有其签名私钥，测试版会并存，不能自动继承正式版私有登录数据。
在“设置 → 插件”刷新列表，已安装的 QQ、网易云、汽水从各自“设置”进入并点“更新”；未安装的从“可安装”进入。相同插件 ID 的更新保留其凭据；不需要先删除音源。
两个平台都登录后，在“我的”顶部打开“我喜欢 · 全部平台”。

## GitHub Release

定制版发布在 `tengyuanxingxing/qplayer`，标签 `v1.9.14-custom`，标记为预发布。
Release 附件使用已完成本地构建与验证的 APK 和三个插件，保留上一版测试包的签名与应用 ID。
统一发布工作流对包含 `-custom` 的标签跳过上游平台构建，避免上传不同签名、不同应用 ID 的上游 release 变体。常规标签保留原工作流行为。
不上传本机签名私钥、GitHub 凭据或音乐平台登录数据；源码、中文发布说明和校验文件随版本提供。

从 1.9.11 起，内置目录中上述三个插件改为读取用户自己的对应仓库，保持上游插件 ID。在线包使用定制发布者独立签名，公钥固定在内置目录中；并未放宽在线包的签名验证。其余插件仍使用原目录与原发布者公钥。
三个定制插件独立发布稳定 Release，既有目录的 `releases/latest` 查询、安装和更新提示可直接沿用，后续插件更新无需重新安装 APK。
